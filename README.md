# PARKA Bakehouse (website concept)

6 static pages, English + Arabic (RTL) with a language switch.

- index.html: Home (hero with a live "table" preview, signature dishes, garden, reviews, celebrations)
- menu.html: "Build your table" menu. 74 real menu items with prices, mood presets,
  dishes land on a wooden table, live ticket with per-person split, pairing suggestions,
  coffee finder, and pickup order / table booking sent on WhatsApp (+971 52 476 6484)
- cakes.html: Whole cakes (AED 249–299) + Bakes Box, pre-order form to WhatsApp
- celebrate.html: Anniversaries / birthdays enquiry form to WhatsApp
- reviews.html: Google reviews (4.8 from 3,427) with filters
- visit.html: Address, hours, map, photos

Menu data lives in assets/js/menu-data.js (generated). Edit prices/names there.
Arabic link: add `?lang=ar`.
